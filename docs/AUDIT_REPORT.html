StealthLib verification policy

This page intentionally does not assign a quality score or claim current results from external scanners, fuzzing campaigns, coverage, or mutation tools. Such results are valid only for the exact revision, configuration, compiler, and tool version that produced them.

For v2.2.2, the repository defines reproducible CMake/CTest checks for core APIs, PE forwarders, IAT comparison, package installation, and subproject integration. Run:

cmake -S . -B build -DSTEALTH_BUILD_TESTS=ON
cmake --build build --parallel
ctest --test-dir build --output-on-failure

Static-analysis, sanitizer, and fuzzing jobs must fail when their invoked tool reports failure. Their current CI definitions enforce command failures rather than masking them with success fallbacks.
